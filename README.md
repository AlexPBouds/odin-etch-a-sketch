# Odin Etch-a-Sketch

## Functionality

- Hovering
  Hovering your mouse over a square will color it and darken it. The more you mouse-over the same square, the darker it will get, until the square is fully black. If the page is refreshed, or the grid is reset, all squares are changed back to white.
- Change Grid Size Button
  Pressing this button opens a prompt asking you to change the grid size. The value you input has to be an integer, and it has to be between the range of 16-100 (inclusive). Cancelling the prompt simply keeps the grid as is, leaving your progress intact.
- Reset Grid Button
  Pressing this button resets all the squares to white while keeping the size of the grid the same. This function is run when the website is restarted.
